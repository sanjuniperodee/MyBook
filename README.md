# MyBook — персональные книги-подарки

Сервис, в котором человек пишет книгу для близкого: отвечает на продуманные вопросы, добавляет фотографии, выбирает обложку — и получает книгу, свёрстанную как настоящее издание. Готовые PDF (блок и развёртка обложки) сразу подходят для типографии.

## Возможности

**Для клиента**
- Лендинг с живыми 3D-обложками, тарифами и FAQ.
- 4 темы книги: любимому человеку (176 вопросов, 19 глав), маме и папе (по 81), другу (45).
- Формулировки подстраиваются под род автора и адресата: «ты увидел / ты увидела».
- Редактор вопросов: автосохранение, навигация без перезагрузки, список всех вопросов с поиском, свои вопросы, правка и скрытие заголовков, счётчик страниц, живое превью страницы (те же шрифты и поля, что в PDF).
- 11 генеративных обложек и обложка с вашим фото. Текст, подзаголовок, имена, текст на задней стороне.
- Фото: загрузка с перетаскиванием, сортировка, подписи, три макета (в рамке / на всю страницу / по два), предупреждение о низком разрешении для печати.
- Оформление: 3 стиля вёрстки, 2 формата (A5 и 200×200), посвящение, оглавление, размещение фото.
- Предпросмотр всей книги в PDF (с водяным знаком) до оплаты.
- Оформление заказа, оплата (перевод или карта через CloudPayments), статусы и письма на каждом этапе, скачивание PDF.

**Для бизнеса**
- Админка: выручка, заказы, требующие внимания, фильтры и поиск, смена статусов с письмом клиенту, трек-номер, журнал событий, заметки.
- Выгрузка для типографии одним ZIP: `block.pdf`, `cover.pdf`, `spec.txt` (техзадание с размерами развёртки, корешком и координатами сгибов).
- Можно временно открыть книгу клиенту для правок и перегенерировать файлы.

## Файлы для типографии

| Файл | Что внутри |
|---|---|
| `block.pdf` | Блок книги. Формат с вылетами 3 мм с каждой стороны, `TrimBox`/`BleedBox` на каждой странице, объём не меньше 24 стр. и кратен 4 (добавляются чистые страницы). Шрифты внедрены, фото 300 dpi. |
| `cover.pdf` | Развёртка твёрдой обложки: загиб | задняя крышка | шарнир | корешок | шарнир | передняя крышка | загиб. Ширина корешка считается по числу страниц. Текст векторный, графика 300 dpi. |
| `spec.txt` | Техзадание: формат, объём, размеры развёртки и крышек, корешок, координаты сгибов. |

Параметры печати (толщина листа, загиб, шарнир, кант, минимальный объём) — в `src/lib/book/formats.ts` (`print`). **Перед запуском сверьте их с требованиями вашей типографии.** Цвет в файлах — RGB (sRGB); цифровые типографии принимают его как есть. Если типография требует CMYK/PDF-X, конвертацию делает препресс.

## Стек

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, PostgreSQL + Drizzle ORM, `@react-pdf/renderer` + `pdf-lib` (вёрстка PDF), `sharp` (фото и растрирование обложек), русские переносы `hyphen`. Шрифты с полной поддержкой кириллицы и казахских букв лежат в `assets/fonts` и используются и на сайте, и в PDF.

## Быстрый старт (разработка)

Нужны Node.js ≥ 20.9 и PostgreSQL ≥ 14.

```bash
npm install
cp .env.example .env            # заполните DATABASE_URL и ADMIN_EMAILS
npm run dev                     # миграции БД применяются автоматически при старте
```

Откройте http://localhost:3000. Пользователь, зарегистрировавшийся с адресом из `ADMIN_EMAILS`, получает права администратора. Или создайте администратора командой:

```bash
npm run create-admin -- admin@example.com 'надёжный-пароль'
```

Демокнига с ответами и фото + все PDF в папку `./sample-out`:

```bash
npm run sample-book -- ./sample-out
```

## Продакшен (Docker)

```bash
cp .env.example .env    # APP_URL=https://ваш-домен, SMTP, оплата, POSTGRES_PASSWORD
docker compose up -d --build
```

- Приложение слушает порт 3000; поставьте перед ним reverse proxy с HTTPS (Caddy / Nginx). Для загрузки фото разрешите тело запроса до **80 МБ** (`client_max_body_size 80m;`).
- Данные: том `pgdata` (база) и том `storage` (фото, готовые PDF). **Настройте регулярный бэкап обоих.**
- Создать администратора в контейнере: зарегистрируйтесь с адресом из `ADMIN_EMAILS`.
- Генерация файлов печати для книги на 150–250 страниц занимает 10–60 секунд и использует до ~1 ГБ памяти — выделите серверу минимум 2 ГБ RAM.

## Настройка

| Что | Где |
|---|---|
| Название, контакты, реквизиты, отзывы | `src/config/site.ts` |
| Цены тарифов и доставка | `src/config/site.ts` (`plans`, `deliveryOptions`) |
| Реквизиты для оплаты переводом | `src/config/site.ts` (`manualPayment`) |
| Вопросы и главы | `src/lib/content/*.ts` (синтаксис рода: `{м|ж}` — автор, `[м|ж]` — адресат) |
| Обложки | `src/lib/book/covers.ts` |
| Форматы и параметры печати | `src/lib/book/formats.ts` |
| Стили вёрстки | `src/lib/book/fonts.ts` |
| Тексты оферты и политики | `src/app/offer`, `src/app/privacy` |

Вопросы копируются в книгу при её создании, поэтому банк вопросов можно свободно менять — уже начатые книги не пострадают.

### Переменные окружения

См. `.env.example`. Главное:
- `APP_URL` — публичный адрес (для писем и cookie `Secure` при https).
- `DATABASE_URL`, `STORAGE_DIR`.
- `ADMIN_EMAILS` — кто получает права администратора.
- `SMTP_*`, `MAIL_FROM`, `ORDERS_NOTIFY_EMAIL` — почта. Без SMTP письма пишутся в лог.
- `PAYMENT_PROVIDER` — `manual` или `cloudpayments`.

### Оплата

**`manual`** (по умолчанию) — клиент видит реквизиты для перевода (Kaspi и т.п.) и нажимает «Я оплатил(а)». Администратор получает письмо, проверяет поступление и ставит статус «Оплачен».

**`cloudpayments`** — оплата картой, Apple Pay и Google Pay через виджет CloudPayments (работает в Казахстане и России):
1. Укажите `CLOUDPAYMENTS_PUBLIC_ID` и `CLOUDPAYMENTS_API_SECRET`.
2. В личном кабинете CloudPayments включите уведомления (формат по умолчанию, UTF-8):
   - Check → `https://ваш-домен/api/payments/cloudpayments/check`
   - Pay → `https://ваш-домен/api/payments/cloudpayments/pay`
   - Fail → `https://ваш-домен/api/payments/cloudpayments/fail`

Подпись уведомлений (HMAC) проверяется, сумма и номер заказа сверяются с базой.

## Структура

```
src/
  app/            страницы: лендинг, (auth), (app) — кабинет и редактор, admin, api
  components/     UI: обложки, редактор, лендинг
  config/site.ts  коммерческие настройки
  lib/
    content/      банк вопросов и темы
    book/         форматы, шрифты, обложки, вёрстка и оценка объёма
    pdf/          генерация блока, обложки, пакета для типографии
    db/           схема Drizzle и подключение
    orders.ts     заказы, статусы, письма, файлы
assets/fonts      шрифты для сайта и PDF
drizzle/          миграции
```

## Перед запуском

- [ ] Заполнить реквизиты и контакты в `src/config/site.ts`, проверить цены.
- [ ] Проверить тексты оферты и политики конфиденциальности с юристом.
- [ ] Сверить параметры печати (`print` в `formats.ts`) с типографией и отдать им тестовый пакет (`npm run sample-book`).
- [ ] Настроить SMTP и `ORDERS_NOTIFY_EMAIL`.
- [ ] Подключить оплату (CloudPayments или реквизиты для перевода).
- [ ] HTTPS, бэкапы базы и тома `storage`.
- [ ] Добавить реальные отзывы клиентов в `site.testimonials` — секция на лендинге появится автоматически.
