# packages

Общие пакеты монорепо. Пока пустые заготовки: код не переносится до M1.1.

| Пакет | Назначение |
|---|---|
| `@mybook/contracts` | DTO, коды ошибок, схемы событий, типы OpenAPI. Единственное, что может импортировать и web, и api |
| `@mybook/platform-kit` | env-схемы, логгер, OTel, тестовые утилиты, auth-контекст |

Правила:

- `contracts` не импортирует `modules`, `server`, `shared/infrastructure` и Next.js.
- `platform-kit` может импортировать `contracts`, но не модули.
- Пакеты не тянут БД и бизнес-логику: только типы/инфраструктура.
