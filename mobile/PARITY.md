# Паритет «сайт ↔ приложения» (CRM 1.7.0, клиент — v1 в разработке, 25.11.2026)

Два приложения из одной кодовой базы — CRM для сотрудников и «MyBooks» для авторов (mobile/CLIENT-APP.md).

Новые экраны CRM берут данные только из контракта API v1 (`packages/contracts/src/v1/crm.ts`, ADR 0012), не из ручных
маршрутов. Порядок переноса со страниц CRM — по частоте: правка сделки и клиента, бот (1.5.0) → деньги и трек заказа (1.5.2) → доски (1.6.0) → файлы
заказа, обращения, новый клиент со сделкой (1.7.0) → финансы, реестр продаж и аналитика для руководителя.

Правило: что продажник и руководитель делают каждый день — экраном приложения; остальное открывается **страницей CRM
внутри приложения** (встроенный браузер `CrmWebScreen`, уже вошедшим: `POST /api/mobile/web-session` — отдельная
сессия, «Выйти» на сайте не закрывает приложение). Права везде те же, что на сайте: экраны приложения ходят в те же
server actions (`assertStaff`, роли), страницы — это сам сайт. Дыр нет: каждая страница боковой панели CRM доступна.

Обозначения: **экран** — своё в приложении; **CRM** — страница CRM во встроенном браузере (кнопка ↗ «Открыть в CRM» или
раздел в «Профиле» / «Ещё»); **≈** — работает иначе, чем на сайте.

## Уведомления

| | Сайт | Приложение |
|---|---|---|
| Колокольчик, плашки | есть | экран и плашки при открытом приложении |
| Push | Web Push | iPhone — APNs (включён), Android — FCM (ждёт ключ Firebase) |
| Нажатие | открывает страницу | чат, сделка, клиент, заказ, обращение — экраном; финансы, настройки — CRM внутри приложения |
| Прочитанное | снимается | снимается в колокольчике, шторке и на значке |

## Дизайн

Палитра и тёмная тема — `html.crm` (`lib/ui/tokens.dart`), винная главная кнопка, rose — свои сообщения, info — бот,
аватары тонами CRM, экран входа как CRM. Страницы CRM во встроенном браузере — это сам сайт (его тема).

## Что работает иначе

- Канбан заказов и доска сделок на телефоне — списки по статусам (как мобильная вёрстка сайта); доска — через CRM.
- Звонок WhatsApp — через страницу CRM внутри приложения, а не нативный экран звонка.
- iPhone ставится не из App Store: регистрация телефона на `/admin/app` и установка по ссылке (Ad Hoc).

## Клиентское приложение «MyBooks» (кабинет автора `src/app/(app)/*`)

**экран** — готово в приложении; **v2/v3** — запланированный выпуск; **контракт** — ждёт маршрута `/api/v1`.

| Кабинет сайта | Путь | Приложение |
|---|---|---|
| Вход | `/login` | экран (вход клиента — контракт) |
| Мои книги | `/books` | экран как на сайте: объёмная обложка (картинка печатной), тема, прогресс, срок к празднику, заказ, «Продолжить писать», «Другие книги»; кэш без сети |
| Новая книга | `/books/new` | v1, контракт |
| Книга | `/books/<id>` | экран как на сайте: следующий шаг, отсчёт до праздника, путь книги, замечания, главы, письма, помощь; помощник по книге (кнопка справа внизу) |
| Вопросы и ответы | `/books/<id>/questions` | экран: ответ засечками, автосохранение, очередь без сети; голос → текст — v1; свои видео и аудио по QR — v3 |
| Фото | `/books/<id>/photos` | экран как на сайте: итоги, фильтры, правило книги, подпись места, лист «Где стоит фото» (место, вид, подпись, удаление), загрузка; кадр и редактор фото — v3 |
| Превью, чтение, 3D-книга | `/books/<id>/preview` | экран как на сайте: сборка макета с ходом и повтором, читалка по страницам (ползунок) и «Все подряд», плашки «обновляем» / «прошлая версия», PDF в «Поделиться», 3D-книга пальцем, «Всё отлично — заказать»; API v1 `bookBuild`, `bookBuildProgress` |
| Обложка | `/books/<id>/cover` | v3 |
| Страницы, оглавление | `/books/<id>/pages` | v3 |
| Письма близких | `/books/<id>/letters` | v3 |
| Настройки книги | `/books/<id>/settings` | v3 |
| Заказ и оплата | `/books/<id>/checkout` | экран как на сайте: тариф, экземпляры, допы, договорённость; доставка и адрес, получатель, подарок (открытка, дата, сюрприз); промокод, проверка макета, согласие; итог считает сервер; дозаказ печатной к электронной — сайт |
| Заказы, статус | `/orders`, `/orders/<id>` | экран: мои заказы, заказ (что сейчас, этапы, трек, детали, чек), оплата Kaspi (счёт по номеру, QR, ожидание) и переводом («Я оплатил(а)»), отмена; файлы книги после оплаты и отзыв — следующим выпуском |
| Отзыв | `/review` | v3 |
| Помощник по книге | чат в кабинете | экран: беседа, частые вопросы, «Позвать менеджера», WhatsApp, если выключен |
| Аккаунт | `/account` | вкладка «Аккаунт»: имя, телефон, выход; правка профиля и пароля — v3 |
| Push клиенту | письма и WhatsApp | v1 (APNs/FCM уже есть у CRM) |
