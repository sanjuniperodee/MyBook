# Свои видео и аудио по QR-коду

Клиент загружает к ответу своё видео или аудио (голосовое WhatsApp, диктофон), сервер его сжимает и хранит, а в книге
печатается QR-код страницы `/v/<токен>` с проигрывателем. Та же карточка, что у ссылок на YouTube (`answer-media.ts`),
поэтому превью, PDF и электронная версия работают без отдельной вёрстки; у аудио — свой вид «Аудио».

## Как устроено

| Часть | Где |
| --- | --- |
| Лимиты, разбор ffprobe, параметры ffmpeg, минуты книги | `src/lib/book/answer-files.ts` |
| Загрузка кусками, учёт минут, покупки пакетов, страница | `src/server/answerFiles.ts` |
| Очередь обработки (ffmpeg) | `src/server/answerFilesWorker.ts` |
| API редактора | `/api/books/<id>/files` (GET, POST), `/files/<fileId>` (GET, PUT кусок, POST готово, DELETE), `/files/packs` |
| Файл по токену (Range, `?poster=1`, `?download=1`) | `/api/v/<токен>` |
| Страница по QR-коду | `src/app/v/[token]/page.tsx` |
| Редактор | `components/editor/questions/FileUpload.tsx`, `MediaStrip.tsx` |
| Таблицы | `answer_files`, `answer_file_purchases` (миграция 0089) |

- **Загрузка**: куски по 8 МБ (nginx пропускает до 80 МБ, на мобильной сети обрыв дешёвый), каждый пишется по своему
  смещению — повтор после обрыва безопасен; браузер сам продолжает с места, которое сервер получил.
- **Проверки до загрузки**: тип, размер (до 1 ГБ), длительность по метаданным в браузере (видео до 10 мин, аудио до 30),
  минуты книги, свободное место на диске (запас 3 ГБ) и общий объём ждущих исходников (до 4 ГБ).
- **Обработка**: по одному файлу на процесс, `nice -n 15`, 2 потока. Видео — H.264 CRF 26 с потолком 1,5 Мбит/с, кадр
  вписан в 1280×720 (вертикальное — 720×1280), до 30 к/с, AAC 128k, `+faststart`; аудио — AAC 128k в M4A. Кадр-обложка
  JPEG. Минута видео ≈ 11 МБ. Очередь в базе: переживает перезапуск, зависшая обработка (нет отметки 5 минут) берётся
  заново, до 3 попыток. Запуск — после загрузки, через минуту после старта сайта и в планировщике раз в 15 минут.
- **Хранение**: исходник — `cache/answer-uploads/<id>.src` (в бэкап не идёт, удаляется после обработки), готовое —
  `answer-media/<книга>/<файл>/media.mp4|m4a` и `poster.jpg` (входит в `deploy/media-backup.sh` вместе со всем
  хранилищем). Удаление книги удаляет и папку.
- **Уборка** (планировщик): незаконченные за сутки загрузки; исходники без записи старше 2 суток; файлы без карточки ни в
  одном ответе старше 14 дней — только у незаказанных книг. У заказанной книги файлы не удаляются никогда.

## Минуты и пакеты

Бесплатно 30 минут на книгу; пакеты +30/+60/+180 минут (Kaspi, цель `media_pack`, комментарий «MyBooks M<n>»). Всё в
«Ценах и тарифах»: число бесплатных минут и галочка «Продаётся» у пакетов. Сейчас пакеты не продаются — клиент не видит
ни цен, ни предложений; когда минуты кончились, редактор предлагает удалить ненужный файл или добавить ссылкой.
Купленные минуты считаются в лимите книги сразу в транзакции оплаты; неучтённые оплаты видны в «Финансах».
