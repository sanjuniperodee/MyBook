# Доски задач (уровень Trello)

Модуль `src/modules/boards`, экраны `src/app/admin/tasks/boards`, `src/app/admin/tasks/calendar`, API сайта
`/api/admin/boards/…` (`src/server/boards-api.ts`), API v1 — `packages/contracts/src/v1/boards.ts`.

## Для сотрудников — коротко

- **Где:** боковая панель → «Доски» и «Календарь» (или кнопки на странице «Задачи»). «Мой день» и «Задачи» работают как
  раньше: карточка доски — это та же задача CRM.
- **Доски:** «Продажи» (сюда сами попадают задачи из сделок, правил и бота), «Производство книги» (Новые → Макет →
  Согласование → Печать → Доставка → Готово), «Поддержка». Свою доску или проект — «Создать доску», шаблон.
- **Карточку** перетаскивают между колонками и внутри колонки; в «Готово» — выполнена. Нажали — открывается целиком:
  исполнители (первый — главный, ему напоминание), наблюдатели («Следить»), метки, приоритет, начало и срок, напоминание,
  описание, чек-листы с исполнителем и сроком у пункта, вложения (перетащите файл; первая картинка — обложка),
  комментарии с @Имя, журнал, повтор («каждую неделю» — после выполнения появится следующая), оценка и затраченное время.
- **Виды:** Доска · Список (сортировка, массовые действия) · Календарь (перетащите карточку на день или час — срок
  поменяется; двойной клик по пустому месту — новая карточка) · Шкала (полосы от начала до срока, тянутся мышью).
- **Фильтры:** «Мои», «Просрочено», «На сегодня», «Фильтры» (исполнитель, метки, приоритет, срок, выполненные),
  «Сохранить фильтр». Дорожки — по исполнителю (перенос между дорожками меняет исполнителя), метке, приоритету.
- **Клавиши:** `n` — новая карточка, `/` — поиск, `e`/Enter — открыть карточку под мышью, пробел — взять себе,
  `c` — в архив, `q` — только мои, `1–4` — виды, Shift+клик — выбрать несколько, `?` — подсказка.
- **Автоматизация доски** («Настроить» → «Автоматизация»): «Когда карточку перенесли в колонку / появилась / выполнили /
  прошёл срок / чек-лист выполнен — назначить (в т. ч. того, кто перенёс), поставить срок, уведомить, метка, перенести,
  чек-лист, приоритет». На каждой доске уже есть «Срок прошёл — метка „Просрочено“» (снимается сама, когда срок
  перенесли или карточку выполнили).
- **Правило CRM** («Автоматизации» → действие «Создать карточку на доске»): например, «Сделка перешла на этап
  „Оплачено“ → карточка „Книга для {имя}“ на доске „Производство книги“ с чек-листом».
- **Календарь в телефоне:** «Календарь» → «Подписка по ссылке (iCal)» — ссылка для Google/Apple Календаря (только
  чтение). «Google Календарь» → «Подключить» — двусторонняя синхронизация в отдельный календарь «MyBooks CRM»
  (перенесли событие в Google — поменяется срок; новое событие — карточка на вашей личной доске). В Google — только
  название и ссылка на карточку.

## Устройство

- Карточка = строка `crm_tasks` (колонки `board_id`, `column_id`, `position`, `priority`, `start_at`, `cover`, `archived_at`,
  `recurrence`, `book_id`, `conversation_id`, `meet`, `updated_at`). `board_id IS NULL` — доска по умолчанию
  (`crm_boards.is_default`), без колонки — первая (выполненная — в «Готово»): старый код задач досок не знает и не теряет.
- Живое обновление: триггер `crm_tasks_live` шлёт `pg_notify('crm_live', {type:"board"})` на любую запись карточки
  (из досок, «Задач», сделок, правил, бота), SSE `/api/admin/live/stream` → `window` событие `crm:live` → доска
  перечитывает себя. `updated_at` ставит триггер `crm_tasks_touch`.
- Правила досок (`crm_board_rules`) выполняет `CardsService` сразу после события; «срок прошёл» и повторы — проход
  планировщика (`board rules`, `recurring cards`); Google — `google calendar` (минутный проход CRM).
- Права: общая доска — всем, закрытая — участникам и праву `boards.manage`; карточка о клиенте у роли «только свои» —
  своя, ничья, где соисполнитель или наблюдатель (как в «Задачах»); внутренняя — всем, кто видит доску.
- Google: ключи `google.clientId` / `google.clientSecret` («Интеграции → CRM» или `GOOGLE_CLIENT_ID/SECRET`), scope
  `calendar.app.created`, redirect `https://mybooks.kz/api/integrations/google/callback`, push-канал
  `/api/integrations/google/webhook` (продление за сутки до конца), без канала — опрос раз в 10 минут; токены
  зашифрованы (`crm_google_accounts`), связи событий — `crm_google_events`.
- Тесты: `tests/boards.test.ts`, `INTEGRATION=1 … tests/boards.integration.test.ts`, `tests/boards-google.integration.test.ts`.
