# 3D-книга в приложении MyBooks — сверка с сайтом (26.11.2026)

Одна и та же книга (104 стр.) на сайте («Макет и 3D», three.js) и в клиентском приложении (`Book3DView`),
восемь ракурсов: начальный, обложка, корешок, оборот, срез, сверху, снизу, «Читать».

- `before/site-sheet.jpg` — сайт (эталон), `before/app-sheet.jpg` — приложение до переделки.
- `after/app-sheet.jpg` — приложение после; `after/app-opened.jpg` → `after/app-spread-next.jpg` — листание нажатием.

## Что было не так (до)

- Книга собиралась из `Transform`-плоскостей: грани без сортировки по глубине — корешок и блок просвечивали,
  между гранями щели, при повороте мерцание (z-fighting).
- Свои числа в коде (загиб, шарнир, толщина листа, свет), не те, что у сайта: другие пропорции и толщина блока.
- Нет студии сайта (купол, стол, туман, мягкая тень), другой свет, нет тонмаппинга — книга темнее и плоская.
- Камера без инерции и автоповорота как у OrbitControls; ракурсы и «Читать» прыгали без анимации.
- Листание без изгиба листа, нажатие не различало правую и левую страницу.

## Что сделано (после)

- Общие числа сцены — `src/lib/book/book-scene.ts` (камера, ракурсы, «Читать», орбита, листание, свет, студия,
  материалы, тень корешка). Сайт (`BookScene.ts`, `BookViewerGL.tsx`, `textures.ts`, `materials.ts`,
  `geometry.ts`) берёт их оттуда, приложение получает их с сервера в `bookModel.scene` (API v1).
- Приложение рисует настоящую 3D-сцену: свой растеризатор на `Canvas.drawVertices` (перспектива, отсечение
  обратных граней, сортировка по слоям и глубине, освещение вершин как у three.js + neutral tone mapping),
  геометрия повторяет `BookScene.apply` (крышки, корешок, стопки по окну страниц, лист по кривой изгиба).
- Студия — фрагментный шейдер `mobile/shaders/studio.frag` (купол, стол, туман, мягкая тень 5×5, контактная тень).
- Камера: инерция, автоповорот, анимированные ракурсы и «Читать», щипок — зум, нажатие — листание
  (правая страница/обложка — вперёд, левая — назад).
- Тесты: `mobile/test/client_book3d_test.dart` на книгах 60/104/200 стр. (`test/fixtures/book_model_*.json`):
  книга в кадре, попадание нажатием, толщина корешка растёт со страницами, кадр ≈ 4 мс (JIT, 200 стр.).

## Не проверено / отличается

- FPS на живом iPhone и Android-эмуляторе (на симуляторе профиль недоступен; по тесту кадр ≈ 4 мс).
- Нет сглаживания краёв силуэта (drawVertices без MSAA), нет самозатенения книги.
- Нет зерна купола и текстуры полос на срезе блока; ползунка «Раскрытие книги» в приложении нет.
