Проект — `/Users/sanjuniperodee/MyBook`, ветка `claude/crm-polish`, Next.js 16 (в `AGENTS.md`: API могут отличаться от
привычных — перед правкой серверных API Next читайте `node_modules/next/dist/docs/`). Весь интерфейс по-русски.

## Задача

Полностью пересобрать интерфейс **своей группы страниц** по `docs/design/DESIGN.md` (v2 «Тираж») — **прочитайте его целиком
перед началом**, особенно §2 (чего не делаем), §6 (кит), §7.2 (шаблоны страниц), §9 (адаптив), §10 (как работать).

Основа уже сделана руководителем: токены (`html.crm` для CRM, тёплые токены для сайта и кабинета), кит (`.btn`, `.input`,
`.panel`, `.badge`, `.count`, `.chip`, `.table`, `Panel`, `Badge`, `Field`, `EmptyState`, `Alert`, `Tabs`, `Segmented`,
`StatRow/StatTile`, `Facts`, `SectionHead`, `PageHeader`, скелеты), каркас CRM (рейка, вкладки раздела в шапке, ⌘K).
Ваша работа — **перекомпоновать каждую страницу**, а не перекрасить: другая структура блоков, иерархия, шаблон из §7.2,
плотность, формат строк/карточек, отдельная мобильная раскладка, состояния. Если после правки страница по композиции
почти как раньше — она не сделана, продолжайте.

Принимайте решения сами, не ждите подтверждения, не останавливайтесь после анализа: закончите все страницы группы
(включая `loading.tsx`, пустые состояния, ошибки, диалоги и формы, которые к ним относятся).

## Нельзя ломать

Server actions и их сигнатуры, API-маршруты, права (`can`, `canWork`, `canSeeAssigned`…), загрузку и запись данных,
тексты ошибок сервера, `data-testid`, `id` якорей, `name=` полей форм, маршруты и ссылки между страницами, i18n-ключи,
валидацию. Бизнес-логику не менять; если без этого никак — минимально, с тестом. Функциональность не удалять:
можно менять подачу (например, диалог → боковая панель, таблица → список), но не возможность.

## Границы файлов (параллельно работают ещё девять исполнителей и одна чужая сессия)

- Правьте **только файлы своей группы** (список в задании). Новые файлы создавайте в её папках.
- **Общие файлы не править**: `src/app/globals.css`, `src/app/dark.css`, `src/components/ui/**`,
  `src/components/admin/{AdminNav,CommandPalette,UserMenu,ShiftToggle,PageHeader,Segmented,Tabs,SectionHead,charts,skeletons,Section,Intro,Theme,CrmLive,MobileFilters,useRowSelection,BackLink,ActionMenu,NavMotion,PullToRefresh}.*`,
  `src/app/admin/layout.tsx`, `src/app/admin/template.tsx`, `src/app/layout.tsx`, `src/lib/**`, `src/i18n/**` (словари — см. ниже).
  Нужен общий кит, которого нет, — сделайте **локально** в своей папке (по образцу общего) и перечислите в отчёте в блоке
  «Предложения в общий кит». Мелкая правка общего файла допустима только если без неё нельзя, — тогда прочитайте файл
  заново прямо перед правкой, меняйте минимум и назовите в отчёте.
- **Не трогать** (ведёт другая сессия): `src/components/admin/ChatPanel.tsx`, `src/components/admin/chat/**`,
  `src/components/admin/MobileTabBar.tsx`, `src/app/admin/chats/**`, `src/app/api/admin/chats/**`,
  `src/modules/messaging/infrastructure/chatView.ts`.
- Словари `src/i18n/messages/**` (витрина и кабинет) правят несколько исполнителей: перед каждой правкой читайте файл
  заново, правьте точечно, ключи только добавляйте (не переименовывайте и не удаляйте чужие).
- Ошибки `tsc` и линтера в чужих файлах — не ваши; просто не добавляйте свои.

## Запреты по процессу

Стенд: `http://localhost:3210`, база `mybook_visual`. Снимки:

```
cd /tmp/mybook-shoot && VIEW=desktop|mobile|both [FULL=1] [DARK=1] node shoot.mjs admin|client|public <имя> <путь>…
```

Плейсхолдеры `{deal}`, `{order}`, `{client}`, `{book}`, `{conv}`. PNG — `/tmp/mybook-shoot/out/<имя>-<n>-<вид>.png`
(desktop 1440×900, mobile 390×844); читайте их инструментом Read. Скрипт печатает ошибки консоли и горизонтальную прокрутку.
Для каждой страницы: снимок **до** → правка → снимок **после** (десктоп и телефон; главные страницы ещё в `DARK=1`;
ширины 1024/1280/1920 — через `BASE`/свой вызов Playwright, если страница имеет раскладку по брейкпоинтам) →
исправить найденное → снова. Давайте снимкам свои имена-префиксы (с названием группы), чтобы не затирать чужие.
