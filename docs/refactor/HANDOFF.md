## Подготовка Mac

```sh
git fetch origin && git checkout claude/funny-tesla-gsqj79
npm ci
brew install poppler            # pdftoppm/pdftotext — нужны tests/pdf-critical.test.ts и визуальной сверке
npx playwright install chromium # для снимков HTML
export CHROMIUM_PATH="$(node -e "console.log(require('playwright').chromium.executablePath())")"
npx tsc --noEmit && npx eslint . && npx vitest run
```

Растр зависит от машины: эталон и текущее дерево снимаются на одном Mac (`scripts/visual/check.sh <коммит>` так и делает). Если `tests/fixtures.test.ts` упадёт на sha256 фото — это другая сборка libvips у sharp; пересними хеши у себя одним коммитом, остальные снимки от этого не зависят.

## Как вести шаг

Один шаг — отдельная ветка от головы, атомарные коммиты по-русски, исправления поведения отдельными коммитами «Исправление: …». Перед каждым коммитом: `tsc`, `eslint .`, полный `vitest`; для вёрстки — `bash scripts/visual/check.sh <база шага> --quick`, в конце шага полный. После шага — ревью диффа (можно отдельным агентом), затем слияние в `claude/funny-tesla-gsqj79`. Шаблон оркестрации, которым пользовались в облаке, — `docs/refactor/next/wave-harness.js` (скрипт Workflow; на Mac можно идти по шагам и вручную).
